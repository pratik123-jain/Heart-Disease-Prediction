# ❤️ Heart Disease Prediction System

## 📌 About the Project
The Heart Disease Prediction System is a Machine Learning project that predicts the possibility of heart disease based on patient health parameters. It uses Python and machine learning techniques to support preliminary risk assessment.

## 🎯 Objectives
- Predict the possibility of heart disease using patient data.
- Apply machine learning for health data analysis.
- Provide a simple and user-friendly interface.

## 🛠️ Technologies Used
- Python
- Pandas and NumPy
- Scikit-learn
- Flask
- HTML, CSS and JavaScript
- Machine Learning

## 📂 Project Files
- `app.py` – Main application
- `preprocessing.py` – Data preprocessing
- `train_model.py` – Model training
- `requirements.txt` – Python dependencies
- `heart.csv` – Dataset
- `index.html` – Web page
- `style.css` – Page styling
- `script.js` – Frontend functionality

## 🚀 How to Run

1. Clone the repository:
   ```bash
   git clone YOUR_GITHUB_REPOSITORY_URL
   ```

2. Open the project folder:
   ```bash
   cd Heart-Disease-Prediction
   ```

3. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

4. Run the application:
   ```bash
   python app.py
   ```

5. Open the local URL displayed in your terminal.
